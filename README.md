# Tip Calculator

A simple Python command-line program that calculates how much each person should pay when splitting a bill, including the tip.


## Technologies Used
- Python

## Features
- Takes the total bill amount as input
- Allows users to choose a tip percentage (10%, 12%, or 15%)
- Splits the bill evenly among multiple people
- Displays the final amount each person should pay

## How It Works
1. Enter the total bill amount.
2. Choose the tip percentage.
3. Enter the number of people splitting the bill.
4. The program calculates and shows how much each person should pay.

## Example

    Welcome to the Tip Calculator!
    What was the total bill? $150
    How much percentage tip would you like give? 10, 12, or 15? 12
    How many people to split the bill? 5
    Each person should pay: $33.6
